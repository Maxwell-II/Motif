# Motif

> 随手记录任何一闪而过的想法 —— 秒级捕获,事后整理,回看清爽。
> A desktop quick-capture tool for fleeting thoughts. Capture in a second, organize later.

Motif 是一个**桌面优先**的想法捕获工具。全局快捷键呼出小窗、输入、回车、消失,全程两秒内。想法先落地,分类、优先级、标签全部**事后**再补。

和备忘录 / Notion 的区别:

- **备忘录**写多了就是一坨,只能靠翻和滚动,没结构。Motif 给每条想法挂**自定义标签 + 优先级 + 状态**,靠筛选和搜索找东西,而不是靠回忆「记在哪了」。
- **Notion** 打开慢、要维护文件夹和数据库结构,记一条想法的心理负担太重。Motif 捕获窗**永远只有一个输入框,绝不弹表单**,不打断你。
- 回看时,概览页第一屏就把**高优先级事项、待整理数量、各标签分布、久未更新的沉底事项**摊开给你看,一眼看清全局,而不是面对一整面墙的流水账。

---

## ✨ 特性

- ⚡ **秒级捕获**:全局快捷键(`Ctrl/Cmd + Shift + Space`)随时呼出,输入回车即存,自动隐藏。
- 🏷️ **自定义标签**:自由打扁平标签,不预设分类;侧栏点标签即筛。
- 🎚️ **优先级 + 状态**:P1/P2/P3、收件箱 / 待办 / 完成 / 归档,两三次点击整理一条。
- 🔍 **搜索 + 组合筛选**:按内容搜索,按状态 / 优先级 / 标签任意组合。
- 🗂️ **概览页**:P1 列表、收件箱计数、标签统计、超过 14 天未更新的「沉底区」。
- 📤 **数据可逃逸**:一键导出全部为 Markdown,不锁死。
- 🌗 **深浅色主题** + 🌐 **中英文界面**。
- 💻 **Windows + macOS**,离线可用。

## 🧭 设计红线

Motif 刻意保持克制,这几条是不会破的原则:

1. **捕获永不弹表单** —— 捕获窗只有一个文本框。
2. **没有文件夹** —— 只有标签 / 优先级 / 状态属性 + 筛选视图,永远不「把东西移动到某个位置」。
3. **本地优先** —— 界面永远不等待网络。
4. **删除即软删除** —— 数据留墓碑,可跨设备传播,不悄悄丢东西。

## 🗃️ 数据与同步:文件即真相

Motif **不用数据库**,每条想法就是一个人类可读的 Markdown 文件(带极简 frontmatter),存在你指定的「数据目录」里:

```
<数据目录>/
  items/<uuid>.md      # 一条想法一个文件,正文即 Markdown
  tags/<uuid>.md       # 一个标签一个文件
  conflicts/           # 同步冲突落败文件的归档(自动生成)
```

同步交给你**已有的文件同步工具**(iCloud Drive / OneDrive / Syncthing / Dropbox / git…)——把数据目录指向任意一个被同步的文件夹即可。Motif 本身对同步一无所知:没有服务器、没有账号、没有轮询。

- **自带同步(bring-your-own-sync)**:你的数据,你的同步方式。
- **一次一台设备**:窗口获得焦点 / 启动时重读目录,拾取其他端的改动。
- **冲突策略**:last-write-wins(比较 `updated_at`),按文件内 `id` 去重,落败文件归档到 `conflicts/`,绝不丢数据。
- 所有 `.md` 文件都能用普通文本编辑器打开、手改后被正确加载。

## 🚀 安装

**下载现成安装包**:到 [Releases](../../releases) 下载对应平台的安装包(Windows `.exe` / `.msi`,macOS `.dmg`)。产物未做代码签名,首次打开若被系统拦截,选择「仍要运行」即可。

**或自行构建**(见下)。

## 🛠️ 开发

依赖:[Node.js](https://nodejs.org/) 20+、[Rust](https://www.rust-lang.org/) 稳定版、以及 [Tauri 2 的系统依赖](https://tauri.app/start/prerequisites/)。

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 开发模式(热重载)
npm run tauri build  # 打包当前平台安装包
```

打包产物在 `src-tauri/target/release/bundle/` 下。
